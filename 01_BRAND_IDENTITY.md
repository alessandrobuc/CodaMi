# 01 — Provisional brand identity (CodaMi)

## Name
**CodaMi** (provisional)

## Tagline (optional)
Find and report lost and found pets.

## Logo
- Provisional for the trial
- Place file at `assets/brand/logo.png` when ready
- Prefer: simple animal silhouette + “CodaMi” wordmark
- Formats: transparent PNG + light/dark versions

## App icon
- Target file: `assets/brand/app-icon.png` (1024×1024)
- Primary-color background, light symbol centered
- No long text inside the icon

## Color palette (provisional)

| Token | Hex | Use |
|-------|-----|-----|
| `primary` | `#1F6F5B` | CTA, active tab, brand |
| `primaryDark` | `#145244` | Pressed states / strong headers |
| `accent` | `#F4A261` | Highlights, optional “found” pin |
| `background` | `#F6F8F7` | App background |
| `surface` | `#FFFFFF` | Cards / inputs |
| `text` | `#102A23` | Primary text |
| `textMuted` | `#5C736C` | Secondary text |
| `border` | `#D7E3DE` | Borders |
| `danger` | `#B42318` | Errors / logout |
| `lost` | `#C2410C` | Lost pin / badge |
| `found` | `#1F6F5B` | Found pin / badge |

> Avoid generic purple themes / forced dark mode in the trial. Light theme only.

## Typography
- **UI:** Inter *or* native system fonts (SF / Roboto) for trial speed
- Optional brand font: **Nunito** or **Plus Jakarta Sans** (Google Fonts via `expo-font`)
- Weights: Regular 400, SemiBold 600, Bold 700
- Hierarchy:
  - Screen title ~22–28
  - Section ~13 uppercase muted
  - Body ~16
  - Meta ~13–14

## UI tone of voice
- Clear Italian copy, short sentences (product market is Italy)
- CTAs: “Publish report”, “Contact”, “Mark as resolved”
- Human error messages, not technical jargon

## Brand checklist (trial)
- [ ] CodaMi name on splash / login
- [ ] Primary colors on buttons and tabs
- [ ] Provisional icon in `app.json`
- [ ] No references to old brands (Zamply / Pet Alert)

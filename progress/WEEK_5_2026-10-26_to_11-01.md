# CodaMi: Weekly Progress
**Week 5: Mon 26 Oct to Sun 1 Nov 2026 (in progress, updated Thu 29 Oct)**

## Summary
The client asked for an animal welfare petitions section. It was built on Monday: the CodaMi team picks existing petitions from sites like Change.org, Care2 and Avaaz, checks them, and publishes them in the app. Users read them and sign on the original site.

On Tuesday the app got update checks: users on an older version are told a new one is out, see what changed, and go to the store with one tap. The CodaMi team controls it all from the admin side, without a new app release.

On Thursday the client asked for a CodaMi Shop for pet products. The plan was agreed and Phase 1 started the same day.

## What was built so far

### Animal welfare petitions, Mon 26 Oct
- **Admin → More → Petitions:** add a petition by hand (link, title, platform or organization, topic, country, start date), write our own summary and description (the issue, what it asks for, why it matters for animals), and add an image only when we have permission to use it.
- **Verification:** before approving or publishing, the admin ticks four checks: the page exists, it is a genuine animal welfare issue, it has a clear goal, and no misleading claims. Approving without them is refused, also by the server.
- **Review:** To review → Approved or Rejected (with a reason only admins see) → Published. Users only see published petitions. Status can be set to Active, Completed, Closed or No longer available, and petitions can be edited or deleted at any time.
- **For users:** a banner on Home ("3 animal welfare petitions to sign") and Profile → Petitions. Cards with image, title, summary and source, filters by topic, and a detail page. **View petition** opens the original page in the browser. CodaMi collects no signatures and shows no signature numbers.
- **Security:** only admins can add, change or delete petitions; this is checked on the server, not only in the app. Only https links are accepted.
- **Built to move:** the app talks to petitions through one interface, so a future backend change only replaces one file.
- Tested on the Oppo with an admin and a user account on the live project: the checks refuse empty forms, bad links and publishing without verification; the petition then shows on Home and in Profile, opens the original site, and updates for users when marked "No longer available". Two small form fixes came out of it.
- Translated into all 10 languages. 7 new app tests and 37 new security checks pass; all existing tests (90 app tests, 159 emulator checks) still pass.

### App updates, Tue 27 Oct
- **Automatic check:** every time the app opens, it compares the installed version with the latest version set for Android and for iPhone. It keeps listening while open, so a new release is noticed without restarting.
- **Linked to What's new:** the update message shows the What's new notes of the new version (in the user's language) as soon as they are published in Admin → More → What's new.
- **Update message:** a sheet with the notes appears once per new version, a banner stays on Home (can be hidden for 3 days), and Profile shows "Update available" until the user updates.
- **Update now:** opens CodaMi in Google Play on Android or the App Store on iPhone.
- **Required updates:** an optional minimum version. Anyone below it sees an "Update required" screen and can't use the app until they update (for example after a change old versions can't handle). The admin confirms before turning it on.
- **Managed remotely:** Admin → More → App updates sets the latest and minimum version for each store and the App Store ID. It also shows whether the notes for that version are written and published. Only admins can change it; this is checked on the server.
- Translated into all 10 languages. 6 new app tests and 15 new security checks pass; all existing tests still pass (96 app tests, 174 emulator checks in total).
- Security rules published and the admin side tested on the Oppo: the form checks, the notes status, the update message (once per version, with the notes), "Update now" opening Google Play, and the required update covering the app as soon as it's saved.
- Two improvements came out of the test: admins see a "Continue as admin" button on the "Update required" screen, so a wrong minimum can still be undone from the phone (users never see it), and the keyboard no longer stays open over that screen.
- On iPhone the Update button needs the App Store ID, which exists once the app is on the App Store.

### CodaMi Shop, Thu 29 Oct (Phase 1 started)
- Plan agreed: our own shop inside CodaMi, with connectors for payments, suppliers and affiliate networks that can be swapped later, growing in three phases into a multi-brand marketplace.
- **On/off switch:** Admin → More → Shop. While it's off, users don't see the shop at all; the team can prepare products safely and preview the shop. Turning it on shows the Shop tab to everyone at once, with no app update. It asks for confirmation both ways and starts off.
- **Sales models:** each of the four (our stock, brand partner, dropshipping, affiliate link) can be switched off, which hides all its products.
- **Catalogue in the admin panel:** categories and sub-categories (a starting set of 8 with one tap: food, accessories, care, toys, beds, carriers, tech, other), brands with logo and website, suppliers with contact details and how orders reach them (only admins see suppliers), and products with up to 6 photos, description, category, animals, sales model, brand, supplier, price, price before discount, availability and a visible switch.
- **Switching things off:** hiding a category, brand or supplier also hides its products. Deleting one that is still in use is refused, so nothing breaks.
- **Shop tab for users:** search, filter by animal, categories, and products for the user's own pets shown first. Product page with photos, price and discount, availability and description.
- **Affiliate products:** a "Buy on Amazon" (or other partner) button opens the partner's page, with a clear note that CodaMi may earn a commission. The other products show "Add to cart", which comes with the cart in the next days.
- **Security:** checked on the server. Users can read the catalogue only while the shop is on and only active products; only admins can change anything.
- Translated into all 10 languages. 8 new app tests and 76 new security checks pass, and all the existing tests still pass (104 app tests).
- Security rules published on Thursday; the shop is still switched off for users. Phone test next.

# 07 — Trial milestone (7 days)

## Goal
An Android-installable MVP that demonstrates the core Lost/Found + Map + Pets + Auth flows.

## Definition of Done

### Day 1–2
- [ ] Structured GitHub repo
- [ ] Expo app booting
- [ ] Firebase connected
- [ ] Login / Register / Reset password
- [ ] City setup

### Day 3–4
- [ ] Pets CRUD
- [ ] Create lost report
- [ ] Create found report
- [ ] Home lists (lost / found)
- [ ] Detail + contact

### Day 5
- [ ] Map with pins
- [ ] City / radius filters
- [ ] My reports / My pets

### Day 6
- [ ] In-app notifications (minimum)
- [ ] Firestore/Storage rules published
- [ ] EAS Android build (dev or preview)

### Day 7
- [ ] Bugfix
- [ ] Demo recording / screenshots
- [ ] README updated
- [ ] Handoff notes

## Demo script (5 minutes)

1. Register a new user  
2. Set city  
3. Create a pet  
4. Publish a lost report  
5. Show the pin on the map  
6. Second user (or same with filters) opens detail and contacts  
7. Mark as resolved  

## Do not block the trial for

- Pixel-perfect UI
- Apple login
- Chat
- Admin panel
- Full multi-language system

## Final deliverables

1. Access to repo `main` / `develop`  
2. APK  
3. Firebase project link  
4. Spec respected (this package)  
5. Honest notes / technical debt list
